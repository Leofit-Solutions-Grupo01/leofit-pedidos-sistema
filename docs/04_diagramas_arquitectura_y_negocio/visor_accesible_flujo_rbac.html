🛡️ Pipeline de Middlewares Backend (leofit-backend-api en Render)

Toda petición pasa obligatoriamente por estos 5 filtros perimetrales antes de tocar la base de datos Neon:

PASO 1 Helmet & CORS

Cabeceras HSTS + CSP y filtro de orígenes autorizados.

PASO 2 RateLimiter

Protección anti-DDoS e Idempotency Lock determinista.

PASO 3 Token JWT

Verifica firma HMAC-SHA256 y extrae el rol del usuario.

PASO 4 (CRÍTICO) requireRole('ADMIN')

¿Es ADMIN? Pasa. ¿Es OPERATOR? Corta de inmediato con HTTP 403.

PASO 5 Neon PostgreSQL

Ejecuta SELECT / UPDATE / INSERT con transacciones ACID.

Perfil 1

Administrador (admin@leofit.pe)

Rol: ADMIN — Control Total Operativo y Financiero (100% de llamadas autorizadas con 200/201)

✅ Pasa la compuerta requireRole('ADMIN')
200 OK
GET /api/dashboard/metrics

Métricas de ingresos totales, pedidos por estado y prendas con stock bajo.

Consulta vistas vw_orders_summary + vw_low_stock
201 CREATED
POST /api/products

Crea nueva prenda en el catálogo con categoría, precio base y fotos.

Inserta en tabla products + auditoría audit_log
200 OK
PATCH /api/products/variant/:id/stock

Ajusta físicamente el conteo de stock de una talla/color (SET / INCREMENT).

Modifica product_variants.stock + audit_log
200 OK
DELETE /api/products/:id

Retira una prenda del catálogo preservando integridad histórica (Soft-Delete).

Setea products.deleted_at = NOW() + audit_log
201 CREATED
POST /api/orders (Idempotency-Key)

Registra un nuevo pedido y descuenta stock atómicamente con SELECT FOR UPDATE.

Transacción ACID en orders, order_items y variants
200 OK
POST /api/orders/:id/cancel

Anula el pedido, devuelve automáticamente las prendas al stock y emite Nota de Crédito.

Restituye stock en Neon DB + emite Nota Crédito SUNAT
201 CREATED
POST /api/invoices/emit

Emite comprobante electrónico formal (Boleta de Venta BBB1 o Factura FFF1 con IGV 18%).

Encola en invoice_queue y genera XML firmado + CDR
Perfil 2

Operador Logístico (operador@leofit.pe)

Rol: OPERATOR — Principio de Mínimo Privilegio (Maneja despacho pero tiene prohibido alterar catálogo o anular ventas)

🛡️ Protegido por requireRole('ADMIN')
200 OK
GET /api/products & /alerts/low-stock

Consulta el catálogo de prendas, tallas, colores y alertas para reposición.

SELECT directo en products y product_variants
200 OK
GET /api/orders & GET /api/orders/:id

Visualiza la cola de pedidos pendientes de empaque y seguimiento de rutas.

SELECT en orders con filtros por estado logístico

POST /api/orders (Idempotente)

Registra pedidos recepcionados por WhatsApp y reserva stock físico.

Crea pedido y descuenta stock automáticamente en Neon
200 OK
PATCH /api/orders/:id/status

Avanza el despacho: RECIBIDO -> PREPARACIÓN -> EN CAMINO -> ENTREGADO.

Actualiza tabla orders e inserta en order_status_history
403 FORBIDDEN
