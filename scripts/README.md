## Scripts de diagramas
Requieren `draw.io CLI` o dependencias externas. Sin el, los scripts fallan.
Instalar con: `npm install -g draw.io-cli` (ejemplo).

Scripts:
- generate_bpmn_tobe.py -> diagrams/01_BPMN_TO-BE.png
- generate_user_flow.py -> diagrams/10_User_Flow_Navegacion.png
- generate_risk_map.py -> diagrams/<archivo>.png
